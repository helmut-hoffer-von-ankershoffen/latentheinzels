隐私声明

本页内容以德文版本为准。

版本日期：2026 年 11 月 22 日。

概要

  • 本网站自身不设置 Cookie，不在你浏览器的本地存储（local storage）中保存任何内容，仅在会话存储（session storage）中为影片播放器保留一项记录（第 7 节），也不使用任何分析、跟踪或广告服务。网站的字体、脚本、图片和视频均来自你的设备或本网站。
  • 本网站托管于 GitHub Pages，并通过 Cloudflare 分发。两者均会处理你的 IP 地址等技术数据（第 3 节和第 4 节）。Cloudflare 还会要求你的浏览器向其报告失败的连接。
  • 主打歌的影片及其音乐由本网站提供。你打开主页时，影片即开始加载和播放，除非你的设备要求减少动态效果或节省流量（第 2 节）。
  • SoundCloud 播放器仅在你按下播放键时加载。此时，SoundCloud 会收到你的 IP 地址，并可能设置 Cookie（第 5 节）。

1. 控制者

《通用数据保护条例》（GDPR）第 4 条第 7 项所称的控制者，为网站运营者信息中列明的人士，其通信地址见该处。

电子邮箱：helmut@heinzel.team。如有任何数据保护方面的问题，也请使用该邮箱联系。

2. 我们自行处理的数据

本网站由静态文件组成。我们不运营自有服务器，不自行保存访问日志，也不分析访问情况。我们自身收到的数据仅限于你写给我们的内容（第 6 节）。

主打歌“Berlin Evening: Singularity (Extended Version)”的影片是一个带有声音的视频文件，由本网站自行托管。当你打开包含该影片的页面时，浏览器即开始加载并播放；如果浏览器不允许未经按键就播放声音，则静音播放：此时你在页面上的第一次点击或轻触会打开声音。开启减少动态效果或节省流量时，影片只在你按下播放键后才加载；你暂停之后，也只在你再次按下播放键、重新加载页面或重新访问本网站时才加载。其请求与本网站其他文件的请求一样，会到达 GitHub 和 Cloudflare（第 3 节和第 4 节）。不涉及任何视频或音乐服务。

3. 通过 GitHub Pages 托管

本网站的文件托管于 GitHub Pages，并经由 Cloudflare 传送给你（第 4 节）。GitHub Pages 是 GitHub Inc.（美国，隶属于 Microsoft）提供的服务。根据 GitHub 的说明，访问者访问页面时，无论是否登录 GitHub，其 IP 地址均会出于安全目的被记录并存储。Cloudflare 可能会将你的 IP 地址随请求一并转发给 GitHub。GitHub 的隐私声明指出，还可能收集其他技术信息，例如请求时间、所访问的页面和来源页面。我们无法对这些日志施加任何影响。

  • 目的：安全、稳定地提供本网站。
  • 法律依据：GDPR 第 6 条第 1 款 (f) 项（发布本网站的正当利益）。
  • 接收方：GitHub Inc.，作为处理者，或就其自身的安全日志作为独立控制者。
  • 第三国：美国。GitHub 声明其参加了《欧盟—美国数据隐私框架》（EU-U.S. Data Privacy Framework；欧盟委员会充分性认定，第 (EU) 2023/1795 号实施决定，GDPR 第 45 条），在其他情况下则以标准合同条款为依据（GDPR 第 46 条）。
  • 保存期限：由 GitHub 决定。

4. 分发、防护与错误报告：Cloudflare

本网站的域名使用 Cloudflare, Inc.（美国）的域名服务器，所有对本网站的请求均经过 Cloudflare 的网络。Cloudflare 会解密连接，处理你的 IP 地址、所请求的地址、时间以及你的浏览器发送的技术信息，保留文件副本以加快分发，并可能为运营和保护其网络而记录请求。

Cloudflare 的响应还会要求支持 Network Error Logging（网络错误日志）的浏览器记住连接失败报告的接收地址，最长七天。如果与本网站的连接失败，此类浏览器可能会向 a.nel.cloudflare.com 发送报告，其中包含所访问的地址、错误类型和你的 IP 地址等技术信息。成功的访问不会以这种方式报告。

  • 目的：确保网站可访问，安全、快速地分发内容，以及发现网络错误。
  • 法律依据：GDPR 第 6 条第 1 款 (f) 项。
  • 第三国：美国。Cloudflare 声明其参加了《欧盟—美国数据隐私框架》，并以标准合同条款作为备用依据。
  • 保存期限：由 Cloudflare 决定。

5. 音乐播放器：SoundCloud，仅在你按下播放键之后

打开本网站时，不会向 SoundCloud 发送任何信息。只有在你按下播放按钮时，你的浏览器才会从 w.soundcloud.com 以及该播放器所使用的服务器加载 SoundCloud 播放器。此时，SoundCloud（SoundCloud Global Limited & Co. KG，德国，及其关联公司）会收到你的 IP 地址、浏览器技术信息、本网站地址以及你播放的内容。SoundCloud 可能会设置 Cookie 或使用类似的存储技术；如果你已登录，可能会将上述信息与你的 SoundCloud 账户关联；也可能会将数据传输至包括美国在内的其他国家。此类处理适用 SoundCloud 自身的隐私政策。

  • 目的：播放你选择的音乐。
  • 法律依据：你的同意，即你在看到播放器旁的提示后按下播放键所作出的同意（GDPR 第 6 条第 1 款 (a) 项；就在你设备上进行存储而言，还包括 § 25(1) TDDDG）。
  • 撤回同意：重新加载页面，且不再按下播放键。你可以在浏览器设置中删除 SoundCloud 已存储的内容。
  • 保存期限：由 SoundCloud 决定。

6. 通过电子邮件联系：Cloudflare Email Routing 与 Resend

发往上述邮箱的邮件由 Cloudflare（Email Routing）接收，并转发至控制者的邮箱。Cloudflare 在转发所必需的范围内处理发件人和收件人地址、元数据以及邮件内容。请勿通过普通电子邮件发送敏感数据。

从该域名发出的邮件通过 Resend 服务（Resend，美国）发送。Resend 处理收件人地址、元数据和邮件内容。Resend 在其数据处理协议中声明其适用标准合同条款，并提及《欧盟—美国数据隐私框架》。

  • 目的：答复你的咨询并与你沟通。
  • 法律依据：如果你的咨询旨在订立合同或采取合同订立前的措施，依据 GDPR 第 6 条第 1 款 (b) 项；否则依据 GDPR 第 6 条第 1 款 (f) 项（答复咨询的正当利益）。
  • 保存期限：你的咨询处理完毕且不存在法定保存义务时，我们即删除你的邮件。Cloudflare 和 Resend 适用其各自的保存期限。

7. Cookie 与浏览器存储（§ 25 TDDDG）

本网站自身不设置 Cookie，也不向你浏览器中的本地存储或数据库写入任何内容。影片播放器在会话存储中保留一项记录 latentheinzels-film，包含五个值：film（影片的文件名）、time（已播放到的位置）、paused（你是否暂停了影片）、muted（你是否将其静音）和 heard（影片是否已带声音播放过）。该记录仅用于遵循你的暂停和静音选择，并让影片在你切换页面时继续播放。它绝不会发送给我们或任何其他人，只适用于该浏览器标签页，并在标签页会话结束时由浏览器删除。

你的浏览器可能会照常缓存本网站的文件。Cloudflare 的错误报告指令见第 4 节，SoundCloud 在你按下播放键后可能存储的内容见第 5 节。

8. 指向其他网站的链接

本网站链接至乐队在音乐、视频和社交平台上的主页（“各平台主页”一栏），并在网站运营者信息中链接至控制者本人的网站。这些均为普通链接：在你点击之前，不会从这些网站加载任何内容。只有在点击之后，你才会离开本网站，届时目标网站的运营者将依据其自身的隐私声明处理你的数据。

除上述服务提供商（GitHub、Cloudflare、Resend，以及在你按下播放键之后的 SoundCloud）外，我们不向他人提供个人数据。我们不使用任何征信机构、广告网络或社交插件。

你没有义务向我们提供数据。从技术上讲，没有 IP 地址就无法向你传送网站；你无需按下播放键即可阅读本网站。我们不进行任何自动化决策，包括用户画像（GDPR 第 22 条）。
