隐私声明

本页内容以德文版本为准。

版本日期：2026 年 11 月 22 日。

概要

  • 未经你同意，本网站不设置 Cookie，也不进行访问分析。本网站不使用广告服务。它在会话存储中为影片播放器保存一项记录，并在本地存储中为你的 Analytics 选择保存一项记录（第 7 节）。网站的字体、图片和视频均来自你的设备或本网站。
  • 只有经你允许，才会加载 Google Analytics。届时 Google 会接收有关你访问的数据（包括你的 IP 地址）并设置 Cookie。你可以随时在第 5a 节开头撤回；每个页面页脚的“隐私”都链接到这里。
  • 本网站托管于 GitHub Pages，并通过 Cloudflare 分发。两者均会处理你的 IP 地址等技术数据（第 3 节和第 4 节）。Cloudflare 还会要求你的浏览器向其报告失败的连接。
  • 主打歌的影片及其音乐由本网站提供。你打开主页时，影片即开始加载和播放，除非你的设备要求减少动态效果或节省流量（第 2 节）。
  • SoundCloud 播放器仅在你按下播放键时加载。此时，SoundCloud 会收到你的 IP 地址，并可能设置 Cookie（第 5 节）。

1. 控制者

《通用数据保护条例》（GDPR）第 4 条第 7 项所称的控制者，为网站运营者信息中列明的人士，其通信地址见该处。

电子邮箱：helmut@heinzel.team。如有任何数据保护方面的问题，也请使用该邮箱联系。

2. 我们自行处理的数据

本网站由静态文件组成。我们不运营自有服务器，也不自行保存访问日志。我们仅通过 Google Analytics 分析访问情况，且仅在你允许时进行（第 5a 节）。除此之外，我们自身收到的数据仅限于你写给我们的内容（第 6 节）。

主打歌“Berlin Evening: Singularity (Extended Version)”的影片是一段带有声音的视频，由本网站自行托管。当你打开包含该影片的页面时，浏览器即开始加载并播放；如果浏览器不允许未经按键就播放声音，则静音播放：此时你在页面上的第一次点击或轻触会打开声音。开启减少动态效果或节省流量时，影片只在你按下播放键后才加载；你暂停之后，也只在你再次按下播放键、重新加载页面或重新访问本网站时才加载。其请求与本网站其他文件的请求一样，会到达 GitHub 和 Cloudflare（第 3 节和第 4 节）。不涉及任何视频或音乐服务。

影片有两种大小，整部影片约 45 MB 和 93 MB。播放器会根据你的屏幕尺寸，以及浏览器提供时的网络速度，选择其中一种。这两项信息在你的设备上读取，播放器既不保存也不发送。如果你允许 Google Analytics，它会通过自身的衡量获取屏幕尺寸（第 5a 节）。

3. 通过 GitHub Pages 托管

本网站的文件托管于 GitHub Pages，并经由 Cloudflare 传送给你（第 4 节）。GitHub Pages 是 GitHub Inc.（美国，隶属于 Microsoft）提供的服务。根据 GitHub 的说明，访问者访问页面时，无论是否登录 GitHub，其 IP 地址均会出于安全目的被记录并存储。Cloudflare 可能会将你的 IP 地址随请求一并转发给 GitHub。GitHub 的隐私声明指出，还可能收集其他技术信息，例如请求时间、所访问的页面和来源页面。我们无法对这些日志施加任何影响。

  • 目的：安全、稳定地提供本网站。
  • 法律依据：GDPR 第 6 条第 1 款 (f) 项（发布本网站的正当利益）。
  • 接收方：GitHub Inc.，作为处理者，或就其自身的安全日志作为独立控制者。
  • 第三国：美国。GitHub 声明其参加了《欧盟—美国数据隐私框架》（EU-U.S. Data Privacy Framework；欧盟委员会充分性认定，第 (EU) 2023/1795 号实施决定，GDPR 第 45 条），在其他情况下则以标准合同条款为依据（GDPR 第 46 条）。
  • 保存期限：由 GitHub 决定。

4. 分发、防护与错误报告：Cloudflare

本网站的域名使用 Cloudflare, Inc.（美国）的域名服务器，所有对本网站的请求均经过 Cloudflare 的网络。Cloudflare 会解密连接，处理你的 IP 地址、所请求的地址、时间以及你的浏览器发送的技术信息，保留文件副本以加快分发，并可能为运营和保护其网络而记录请求。

Cloudflare 的响应还会要求支持 Network Error Logging（网络错误日志）的浏览器记住连接失败报告的接收地址，最长七天。如果与本网站的连接失败，此类浏览器可能会向 a.nel.cloudflare.com 发送报告，其中包含所访问的地址、错误类型和你的 IP 地址等技术信息。成功的访问不会以这种方式报告。

  • 目的：确保网站可访问，安全、快速地分发内容，以及发现网络错误。
  • 法律依据：GDPR 第 6 条第 1 款 (f) 项。
  • 第三国：美国。Cloudflare 声明其参加了《欧盟—美国数据隐私框架》，并以标准合同条款作为备用依据。
  • 保存期限：由 Cloudflare 决定。

5. 音乐播放器：SoundCloud，仅在你按下播放键之后

打开本网站时，不会向 SoundCloud 发送任何信息。只有在你按下播放按钮时，你的浏览器才会从 w.soundcloud.com 以及该播放器所使用的服务器加载 SoundCloud 播放器。此时，SoundCloud（SoundCloud Global Limited & Co. KG，德国，及其关联公司）会收到你的 IP 地址、浏览器技术信息、本网站地址以及你播放的内容。SoundCloud 可能会设置 Cookie 或使用类似的存储技术；如果你已登录，可能会将上述信息与你的 SoundCloud 账户关联；也可能会将数据传输至包括美国在内的其他国家。此类处理适用 SoundCloud 自身的隐私政策。

  • 目的：播放你选择的音乐。
  • 法律依据：你的同意，即你在看到播放器旁的提示后按下播放键所作出的同意（GDPR 第 6 条第 1 款 (a) 项；就在你设备上进行存储而言，还包括 § 25(1) TDDDG）。
  • 撤回同意：重新加载页面，且不再按下播放键。你可以在浏览器设置中删除 SoundCloud 已存储的内容。
  • 保存期限：由 SoundCloud 决定。

5a. 访问统计：Google Analytics，仅在你允许时

你的选择：已允许 Google Analytics。你的选择：已拒绝 Google Analytics。你还没有做出选择。

在你按下“接受”之前，不会加载任何 Google 脚本，也不会向 Google 发送任何内容。按下“拒绝”后同样如此。如果你接受，浏览器会从 googletagmanager.com 加载 Google 的衡量脚本（gtag.js），并将有关你访问的数据发送至 Google 的 Analytics 服务器（google-analytics.com 和 analytics.google.com）。我们使用衡量 ID 为 G-EL18RTQ5GY 的 Google Analytics 4，不使用 Tag Manager 容器、广告功能或 Google 信号。

  • 提供方：Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Ireland，依据我们已接受的 Google 数据处理条款代表我们处理数据。
  • 目的：统计访问次数，了解访问涉及哪些页面、语言和国家/地区，以及网站的使用方式。
  • 数据：假名化的客户端和会话标识符、你打开的页面及其地址和标题、来源页面、语言、日期和时间、浏览器、操作系统和设备详情（包括屏幕尺寸），以及精确到城市的粗略位置。精细位置和设备数据的收集按 Google 默认设置处于开启状态。增强型衡量功能已开启全部七项：网页浏览、滚动、点击指向其他网站的链接、站内搜索、视频互动、文件下载和表单互动。Google 表示，它会用欧盟、瑞士和英国访问者的 IP 地址推算粗略位置，随后将其丢弃，不记录也不存储，并且先在当地服务器接收这些数据，再转发处理。
  • 设置：与 Google 共享数据的全部四个选项、Google 信号、用户提供数据的收集以及广告个性化（全部 307 个地区）均已关闭。事件数据中的电子邮件地址遮盖已开启。页面地址中查询参数的遮盖处于关闭状态。
  • Cookie：_ga 通过随机标识符区分浏览器，_ga_EL18RTQ5GY 保存会话状态。两者均针对本网站的主机设置，默认自最近一次更新起最长保留 2 年，并随发往本网站的请求一同发送。
  • 法律依据：你的同意（GDPR 第 6 条第 1 款 (a) 项；就在你设备上存储和读取而言，还包括 § 25(1) TDDDG）。
  • 第三国：Google 可能在美国处理数据，包括通过 Google LLC 处理。Google 表示 Google LLC 参加 EU-U.S. Data Privacy Framework（GDPR 第 45 条），否则依据标准合同条款（GDPR 第 46 条）。
  • 保存期限：事件和用户数据保存 2 个月，新的活动不会重新开始计时。汇总的标准报告不受此设置限制，可能保存更久。
  • 撤回：在本节开头按下“撤回同意”。衡量随即停止，两个 Cookie 被删除，页面会在不含 Google 脚本的情况下重新加载。这不影响此前已进行的处理。

我们还使用 Google Search Console 查看本网站在 Google 搜索中的呈现情况。它不会为本网站添加任何脚本、Cookie 或访客跟踪，只向我们显示来自 Google 搜索本身的汇总统计。

7. Cookie 与浏览器存储（§ 25 TDDDG）

未经你同意，本网站不设置 Cookie。Google Analytics 的 Cookie 见第 5a 节。本网站在本地存储中保存一项记录 latentheinzels-analytics，其值为 allow 或 decline，以便遵循你的选择（§ 25(2) no. 2 TDDDG）。该记录不会被发送，并会一直保留，直到你更改它或在浏览器中删除本网站的数据。

影片播放器在会话存储中保存一项记录 latentheinzels-film，包含五个值：film（影片文件名）、time（播放进度）、paused（你是否暂停了影片）、muted（你是否将其静音）和 heard（影片是否带声音播放过）。该记录仅用于遵循你的暂停和静音选择，并让影片在你切换页面时继续播放。它不会发送给我们或任何其他人，仅适用于该标签页，并在标签页会话结束时由浏览器删除。

你的浏览器可能会照常缓存本网站的文件。Cloudflare 的错误报告指令见第 4 节，SoundCloud 在你按下播放键后可能存储的内容见第 5 节。
